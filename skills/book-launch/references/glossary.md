# 쉬운 말 사전

사용자에게 보이는 모든 글(질문, 결과 문서, 대화)은 이 사전의 **표시 문구**만 쓴다. 내부 용어와 에이전트 이름은 화면에 내보내지 않는다.

- `term_level: plain` (기본): 표시 문구만 쓴다.
- `term_level: with_original`: 표시 문구 뒤에 원래 용어를 괄호로 **처음 한 번만** 붙인다. 예: 본 사람 중 사는 비율(전환율). 이때 괄호 안의 원래 용어는 금지어 검사에서 빠진다. 붙일 자리가 없으면 붙이지 않아도 된다.

처음 책을 내는 사람이 읽는다고 생각하고 쓴다. 사전에 없는 전문 용어가 필요하면 쓰지 말고 풀어서 설명한다.

- 책 제목은 《 》로 쓴다.
- 책의 장을 가리킬 때는 번호만 쓰지 않고 내용을 함께 적는다. 예: 10장 "겸업 규정 확인하는 법".
- "알려주시면 다시 계산합니다"는 누구에게 알리는지 적는다. 예: "이 대화에서 알려주시면". 숫자를 어디서 볼 수 있는지도 한마디 붙인다. 예: "각 앱의 통계 화면".

## 표시 문구

| 내부 용어 | 표시 문구 |
|---|---|
| R, 자기강화 계수 | 주간 판매 흐름 (이번 주 판매가 지난주의 몇 배인지) |
| R 엔진 | 판매를 이어가는 힘 6가지 |
| 사회적 증거 | 남들도 샀다는 증거 |
| 보상 루프 | 저자가 독자에게 답하기 |
| 콘텐츠 재생산 | 독자가 대신 퍼뜨리기 |
| 채널 시너지 | 채널끼리 연결 |
| 부족 형성 | 팬 모임 |
| 검색 자산 | 검색하면 나오는 글 |
| 초기 점화량 | 첫 주 예상 판매 |
| 임계점 | 목표 판매량 |
| 활성 인지 수 | 실제로 보는 사람 수 |
| 활성화율 | 팔로워 중 실제로 보는 비율 |
| 전환율 | 본 사람 중 사는 비율 |
| 메시지 방어력 | 비판에 버티는 힘 |
| C-Score | 콘텐츠 가성비 점수 |
| 대형 파도 | 이번 주 큰 일 |
| 상시 엔진 | 매일 하는 일 |
| 퍼널 | 책 다음에 권할 상품 |
| PHASE n, D-8주 | 출간 8주 전, 출간 주, 출간 후 3주차 |
| 출처 등급 A / B / C / D | 확실 / 조사함 / 비슷한 사례 / 추측 |
| 민감도 | 이것만 알면 판단이 바뀜 |
| 체크리스트, 게이트 | 출간 전 점검 10가지 |
| 레드팀 | 예상 비판과 답 |
| 앵글 | 소개 문구 방향 |
| 바이럴 | 입소문 |
| 서점 MD | 서점 담당자 |
| SEO | 검색에 잘 나오게 하기 |
| lite / standard / full | 빠르게 / 기본 / 꼼꼼히 |
| profile.yaml | 내 책 정보 |
| 1쇄 | 1쇄(처음 찍는 부수) — 처음 한 번만 풀어 쓴다 |
| 서평단 | 미리 읽을 독자 (책을 받은 뒤에는 "미리 읽은 독자") |
| 보도자료 | 언론에 보내는 책 소개 글 (출판사가 쓴다는 점을 처음 한 번 적는다) |
| 인증 | 써도 된다. 처음 한 번은 "인증(따라 한 것을 사진으로 올리는 일)"처럼 풀어 쓴다 |
| 채널 | 써도 된다. 처음 한 번은 "글을 올리는 곳(스레드, 블로그 등)"처럼 예를 든다 |

힘 6가지의 표시 문구를 바꾸면 `scripts/calc.py`의 `FORCES`도 같이 바꾼다.

## 판정 문구

| 계산 결과 | 표시 문구 |
|---|---|
| 가능 | 지금 계획으로 목표에 닿을 수 있습니다. |
| 보강하면 가능 | 조금 모자랍니다. 아래 할 일을 하면 닿을 수 있습니다. |
| 어려움 (첫 책) | 내 채널만으로 팔 수 있는 양은 약 ○○권으로, 목표의 ○%입니다. 나머지는 서점 진열, 출판사 홍보, 입소문에서 나와야 하는데 이 계산은 그 부분을 알지 못합니다. 아래 할 일은 내 채널 몫을 키우고 입소문이 생길 바탕을 만드는 일이고, 목표 달성을 보장하지는 않습니다. |
| 어려움 (실적 있음) | 전작 기록으로 보면 이 목표는 어렵습니다. 예상은 약 ○○권으로 목표의 ○%입니다. |
| 목표 없음 | 지금 채널로는 ○주 동안 약 ○○권이 예상됩니다. 목표를 정하면 닿을 수 있는지 다시 알려 드리겠습니다. |
| 채널 없음 | 글을 올리는 곳이 아직 없어 예상 판매를 계산하지 못했습니다. 올릴 곳 하나를 정하는 것이 첫 할 일입니다. |

- 첫 책의 "어려움" 판정에는 "이 숫자는 책 전체 판매 예상이 아니라 내가 직접 움직일 수 있는 몫입니다"를 붙인다. 낮은 숫자를 책의 성패로 읽지 않게 한다.
- 첫 책의 "어려움" 판정 아래에는 이 계획으로 얻는 것을 한 줄로 적는다. 추측을 실제 숫자로 바꿔 줄 출간 알림 신청 수, 출간 첫 주에 달릴 후기, 다음 책 때 쓸 판매 기록이다. 낮은 숫자만 남기고 끝내지 않는다.
- 할 일이 목표를 채워 준다고 약속하지 않는다. 계산이 모르는 부분은 모른다고 쓰고, 누구에게 물으면 알 수 있는지(출판사 편집자 등)를 적는다.
- 계산 결과에 `scope` 문장이 있으면 판정 바로 아래에 적는다. 숫자가 무엇을 빼고 계산한 것인지 알려 주는 문장이다. 판정 문구와 뜻이 겹치면 한 번만 쓴다.
- 출처가 "추측"인 숫자를 처음 쓸 때 "기본값으로 계산한 추측이라 틀릴 수 있습니다"를 붙인다. 출처 표시의 뜻을 문서 끝에서야 알게 하지 않는다.
- "출간을 미루라"는 말은 출간일을 바꿀 수 있는 사람에게만 한다. 미뤘을 때의 판매 숫자는 계산할 수 없으므로 지어내지 않는다. 미루면 무엇을 더 준비할 수 있는지(채널 키우기, 미리 읽을 독자 모으기 등)를 말하고, 사용자가 미룬 뒤의 팔로워 예상을 주면 그 숫자로 다시 계산한다.
- 낮은 숫자를 감추거나 부풀리지 않는다. 대신 그 숫자를 올리는 방법을 바로 이어서 말한다.
